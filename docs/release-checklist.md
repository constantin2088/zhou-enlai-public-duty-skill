# Release checklist for generated skills

- [ ] Unique GitHub repository name / existing Skill competition checked.
- [ ] Verified primary material and independent scholarly context collected.
- [ ] Distinctive workflow, not an interchangeable personality prompt.
- [ ] Source provenance, attribution and historical periods clearly documented.
- [ ] Modern transfers distinguished from original viewpoints.
- [ ] Three real demos and negative eval cases tested.
- [ ] No TODO / DRAFT placeholders or unverified direct quotes.
- [ ] `python scripts/check_skill.py path/to/generated --release` succeeds.
- [ ] Manual testing in intended runtime succeeds.
- [ ] README, license, contribution and safety docs ready.
