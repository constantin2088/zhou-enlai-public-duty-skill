# Contributing

Welcome changes that improve scaffolding, quality gates and source provenance. Do not submit a whole thinker Skill as a change to this template; publish thinker Skills independently and link them in the [series hub](https://github.com/constantin2088/chinese-thinkers-skills) after verification.

To contribute, provide a short explanation, a passing test and documentation update. Historical quotes must be traceable to credible sources.

Run:

```bash
python -m unittest discover -s tests -v
```
